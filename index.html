    Settings

    These values are stored only in this browser (localStorage) and are never sent anywhere except to the GitHub API for the data repo you configure below.

    For the data repo, enter owner/repo or simply paste the repo's GitHub link (a clone URL works too) — the app works out the owner and name. Use the same repo on every device.

    Archive

    Archive a closed restaurant via its page → Edit restaurant → Archive. Archived ones keep all their visits but never show on the map, and only appear in the list when this is ticked.

    Tags

    Rename or delete a tag on all restaurants at once. Renaming a tag to one that already exists merges the two.

    History

    Every save is kept as a version in your data repo. Look at the state before any save to bring back restaurants that were deleted since.

    Import from Google Maps

    Google doesn't offer a way to read your saved Maps lists directly, so this uses Google's own data export instead. Everything here runs in your browser — the file never leaves your device except as new entries written to your data repo.

    1. Go to takeout.google.com and sign in.
    2. Click "Deselect all", then tick Saved.
    3. Export once, then open the link Google emails you and download it.
    4. Unzip it — inside you'll find one CSV file per Google Maps list you have.
    5. Pick the CSV for the list you want below.

    Each place becomes a wishlist place, unless its note starts with a rating like "7/10" (common if you've been noting your own ratings in Google Maps already) — those import as rated visits instead, with the rating converted to 0–5 stars: 0–5/10 → 0 stars, then 6/10 → 1 star up to 10/10 → 5 stars. You'll see a summary before anything is saved.

    Auto-filled from the CSV's filename once you pick one below — edit or clear it first if you want something different.

    Export

    Downloads everything currently loaded as a CSV file (one row per visit), e.g. to open in a spreadsheet. Nothing is sent anywhere.
